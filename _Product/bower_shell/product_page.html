Overview

Bower Shell is a standalone interactive shell application. It supports both a full REPL mode and single-command execution mode, making it suitable for scripted automation as well as interactive use.

The executable links against bower_shell_lib, meaning the shell engine can be embedded in other products — including MStudio — without code duplication.
