Notepad Product

This is a minimal scaffolding for the `notepad` product that demonstrates using the project's graphics library.

Structure:

- `CMakeLists.txt` — example build entry to integrate with the project
- `src/main.cpp` — minimal example that includes the graphics header and draws a simple window and text

This product is intentionally small and meant as a template. Update include paths and CMake configuration as needed to match the project's actual graphics library location.
