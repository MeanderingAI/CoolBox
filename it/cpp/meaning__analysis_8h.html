Detailed Description

SQL semantic / meaning analysis — validates AST nodes against a schema catalog to verify table existence, column resolution, type compatibility, aggregate correctness, and scope rules.

Works on AST nodes produced by the syntax_analysis/ast library. Requires a SchemaCatalog describing known tables and their columns.
