Detailed Description

Public Methods:

  • UnscentedKalmanFilter(int state_dim, int meas_dim): Constructor specifying the dimensions of the state and measurement vectors.
  • void initialize(const Vector& x0, const Matrix& P0): Initializes the filter with an initial state and covariance.
  • void predict(const std::function<Vector(const Vector&)>& f, const Matrix& Q): Performs the prediction step using the process model and process noise covariance.
  • void update(const std::function<Vector(const Vector&)>& h, const Vector& z, const Matrix& R): Performs the update step using the measurement model, measurement, and measurement noise covariance.
  • const Vector& getState() const: Returns the current state estimate.
  • const Matrix& getCovariance() const: Returns the current state covariance.

Private Methods:

  • void generateSigmaPoints(): Generates sigma points based on the current state and covariance.
  • void computeWeights(): Computes the weights for mean and covariance calculations.
