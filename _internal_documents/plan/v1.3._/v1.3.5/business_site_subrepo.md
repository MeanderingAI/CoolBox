# Sub-Repository: business_site

- **Path:** _sub_repos/business_site
- **Source:** https://github.com/MeanderingAI/business_site.git
- **Added in:** v1.3.5

This sub-repository provides the business_site codebase as a tracked submodule for CoolBox v1.3.5 and later.

## Usage
Clone with submodules:
```bash
git clone --recurse-submodules https://github.com/MeanderingAI/CoolBox.git
```

Update submodules after cloning:
```bash
git submodule update --init --recursive
```
