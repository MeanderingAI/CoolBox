# Sub-Repository: GH-7

- **Path:** _sub_repos/GH-7
- **Source:** https://github.com/MeanderingAI/GH-7
- **Added in:** v1.3.5

This sub-repository provides the GH-7 codebase as a tracked submodule for CoolBox v1.3.5 and later.

## Usage
Clone with submodules:
```bash
git clone --recurse-submodules https://github.com/MeanderingAI/CoolBox.git
```

Update submodules after cloning:
```bash
git submodule update --init --recursive
```
