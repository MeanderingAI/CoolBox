# Sub-Repository: bookish-meme

- **Path:** _sub_repos/bookish-meme
- **Source:** https://github.com/MeanderingAI/bookish-meme
- **Added in:** v1.3.5

This sub-repository provides the bookish-meme codebase as a tracked submodule for CoolBox v1.3.5 and later.

## Usage
Clone with submodules:
```bash
git clone --recurse-submodules https://github.com/MeanderingAI/CoolBox.git
```

Update submodules after cloning:
```bash
git submodule update --init --recursive
```
