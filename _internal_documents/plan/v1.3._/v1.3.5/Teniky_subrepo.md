# Sub-Repository: Teniky

- **Path:** _sub_repos/Teniky
- **Source:** https://github.com/AIMeandering/Teniky.git
- **Added in:** v1.3.5

This sub-repository provides the Teniky codebase as a tracked submodule for CoolBox v1.3.5 and later.

## Usage
Clone with submodules:
```bash
git clone --recurse-submodules https://github.com/MeanderingAI/CoolBox.git
```

Update submodules after cloning:
```bash
git submodule update --init --recursive
```
