# v1.2.6 → v1.2.7 Update Summary

## Deep Learning Refactor and Modularization
- Deep learning code is now modularized into:
  - `DL/layers` (with `src`, `include`, `test`)
  - `DL/loss` (with `src`, `include`)
  - `DL/optimizer` (with `src`, `include`)
  - `DL/wrapper` (with `src`, `include`)
- The old `deep_learning` folder is removed.
- All references and CMake files updated to use the new modular structure.

## CMake & Build System
- Each DL module has its own CMakeLists.txt.
- The main test target for deep learning is `test_deep_learning`.
- All required source files from layers, loss, optimizer, and wrapper are included in the test target.
- The test target links against the local `tyst_framework_main` test framework.
- The Eigen library is now included as an external dependency (downloaded to `external/eigen`).
- The matrix library (`MATRIX/headers/matrix_dense.h`) is used in DL code and included in the build.

## Testing
- All deep learning tests are now built and run via CTest and the test executable.
- 56 tests are registered and passing (unit, integration, and template tests).
- Test discovery and execution are fully automated with CMake/CTest.

## Python & Other Bindings
- Python bindings and CMake integration updated to use the new modular DL structure.
- No changes required for R or JS bindings, but all will benefit from the improved modularity.

## Migration Notes
- If you have custom code using the old `deep_learning` folder, update your includes to the new modular paths.
- When adding new layers, losses, or optimizers, place them in the appropriate DL submodule and update CMakeLists.txt accordingly.
- To add new tests, place them in `DL/layers/test` and add to the test target.

## Validation
- Build and test verified on Windows (MSVC, Makefile.win, CMake, Debug config).
- All tests pass, modularization is complete, and the build system is stable.

---
This update brings a modern, maintainable, and testable structure to all deep learning code in CoolBox. For details, see the main README and CMake files in each DL submodule.
