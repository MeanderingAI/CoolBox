Architecture

The platform is built on a microservices architecture with a shared event bus. Services communicate via REST for synchronous calls and an internal message queue for async workflows. All services are containerised and deployed via CI/CD.

ℹ️ The primary architecture diagram lives in the Mermaid · Diagrams app. Embed a live diagram link here for always-up-to-date visuals.

Contributing to This Wiki

Anyone on the Engineering team can edit pages. Please follow these conventions:

  1. Use clear, concise language — avoid jargon unless defined in the Glossary.
  2. Add your name and date to the article metadata when making significant changes.
  3. Link related pages liberally — the value of a wiki is in its connections.
  4. Use callout boxes to highlight warnings, tips, or important notes.
