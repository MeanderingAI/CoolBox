Install from GitHub

Install the published CoolBox bindings directly from the GitHub repository when you want the latest source instead of a packaged release.

Última versión

Todas las versiones

Python

Install directly from the Python bindings subdirectory with `pip`.

bash
pip install "git+https://github.com/MeanderingAI/CoolBox.git#subdirectory=_libraries/python_bindings"

R

Install the `coolboxr` package from the repository with `remotes` or `devtools`.

r
remotes::install_github("MeanderingAI/CoolBox", subdir = "_libraries/r_bindings/coolboxr")

Go

Fetch the Go module directly from the repository.

bash
go get github.com/MeanderingAI/CoolBox/_libraries/go_bindings@latest

Rust

Git dependencies work for Rust because the repository exposes a top-level Cargo workspace.

bash
cargo add coolbox-rs --git https://github.com/MeanderingAI/CoolBox.git

Java / Maven

Maven does not install dependencies directly from a Git URL. Build and install locally, or publish the artifact to GitHub Packages or Maven Central.

bash
git clone https://github.com/MeanderingAI/CoolBox.git && mvn -f CoolBox/_libraries/java_bindings/pom.xml install
