CoolBox Go Bindings

Go bindings packaged as a standalone module in _libraries/go_bindings.

Module path: github.com/MeanderingAI/CoolBox/_libraries/go_bindings

Install from GitHub

go get github.com/MeanderingAI/CoolBox/_libraries/go_bindings@latest

Import

import coolboxgo "github.com/MeanderingAI/CoolBox/_libraries/go_bindings"
