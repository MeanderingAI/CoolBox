Example — live oscillator
JS synth_example.mjs 
import {
  WavePattern, WaveConfig, AudioBuffer,
  AudioSynthEngine,
  generate_samples_for_duration,
  mix, fade_in, fade_out, low_pass_filter, peak_normalize,
} from '/static/extensions/audio-synth.mjs';

// ── Live oscillator (real-time, keyboard-driven) ──────────────────
const engine = new AudioSynthEngine();
await engine.resume();          // must be called after a user gesture
engine.setMasterGain(0.7);

// Play C4 (261.63 Hz) with a square wave + low-pass filter
const osc = engine.createOscillator({
  frequency_hz: 261.63,
  pattern:      WavePattern.Square,
  gain:         0.4,
});
osc.setFilter(800);            // low-pass at 800 Hz
osc.setFrequency(329.63);    // glide to E4
// ... later ...
osc.stop();

// ── Pre-rendered buffer (generate → process → play) ──────────────
const cfg = new WaveConfig({ amplitude: 0.8, frequency_hz: 440 });
let buf = AudioBuffer.from_samples(
  generate_samples_for_duration(1.0, 44100, WavePattern.Sine, cfg),
  44100
);
buf = fade_in(buf, 2000);       // 2 000-sample ramp in
buf = fade_out(buf, 4000);      // 4 000-sample ramp out
buf = low_pass_filter(buf, 1200);
buf = peak_normalize(buf, 0.9);
engine.play(buf);

// ── Mix two oscillators into one buffer ───────────────────────────
const a = AudioBuffer.from_samples(
  generate_samples_for_duration(1.0, 44100, WavePattern.Sine,
    new WaveConfig({ frequency_hz: 261.63, amplitude: 0.5 })), 44100);

const b = AudioBuffer.from_samples(
  generate_samples_for_duration(1.0, 44100, WavePattern.Sine,
    new WaveConfig({ frequency_hz: 329.63, amplitude: 0.5 })), 44100);

const chord = mix([a, b], [0.6, 0.6]);
engine.play(peak_normalize(chord, 0.9));

C++ usage (native)
C++ synth_example.cpp 
#include "wave_generator.hpp"
#include "audio_processing.h"

using namespace utils::wave_generator;
using namespace trekker::audio;

// Generate 1 second of 440 Hz sine wave at 44 100 Hz
WaveConfig cfg;
cfg.amplitude    = 0.8f;
cfg.frequency_hz = 440.0;

auto samples = generate_samples_for_duration(
    1.0, 44100, WavePattern::Sine, cfg);

// Wrap in AudioBuffer and apply effects
AudioBuffer buf = AudioBuffer::silent(44100, 1, samples.size());
for (size_t i = 0; i < samples.size(); ++i)
    buf.planes[0][i] = static_cast<float>(samples[i]);

buf = fade_in(buf, 2000);
buf = fade_out(buf, 4000);
buf = low_pass_filter(buf, 1200.0f);
buf = peak_normalize(buf, 0.9f);
Libraries used in this demo
🎵 audio-synth.mjs JS
/static/extensions/audio-synth.mjs
Browser-side JS mirror of both C++ audio libraries. Exposes identical API names using the Web Audio API for real-time synthesis and AudioBuffer for offline processing.
🎛 trekker::audio C++
audio_visual_group · VIDEO_ASSETS · audio_processing
AudioBuffer, Resampler, mix, peak_normalize, rms_normalize, fade_in/out, low/high_pass_filter, delay_effect, compress. Emscripten target: audio_processing_js.
〜 utils::wave_generator C++
trekker · MISC · wave_generator
WavePattern (Sine, Square, Triangle, Sawtooth, ReverseSawtooth, Pulse, WhiteNoise), WaveConfig, sample_at, generate_samples, generate_samples_for_duration. Emscripten target: wave_generator_js.
