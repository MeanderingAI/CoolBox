Detailed Description

Defines the ExtendedKalmanFilter class for nonlinear state estimation.

This class implements an Extended Kalman Filter (EKF) for estimating the state of a nonlinear dynamic system. The EKF uses nonlinear process and measurement models, linearized via user-provided Jacobians.
