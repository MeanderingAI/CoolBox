# Predict with a CoolBox linear regression model

Predict with a CoolBox linear regression model

## Usage

``` r
# S3 method for class 'coolbox_linear_regression'
predict(object, newdata, ...)
```

## Arguments

- object:

  A `coolbox_linear_regression` model.

- newdata:

  Numeric matrix or data frame with the same number of columns used
  during training.

- ...:

  Unused.

## Value

A numeric vector of predictions.
