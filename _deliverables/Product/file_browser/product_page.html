Overview

File Browser is a native desktop application providing filesystem traversal within a docked workspace shell. It integrates directly with the graphics::full_application_window::WorkspaceDockHost to present a navigable directory tree inside the standard CoolBox windowed shell.

Filesystem operations are handled by file_browser_lib, keeping the product thin and reusable: the same library powers the file-browser dock panel inside MStudio.
