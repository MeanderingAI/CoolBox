Overview

MStudio is a native desktop editor application built on the CoolBox graphics stack. It provides an integrated workspace with a tree navigator, inspector panel, and editor-state preview, all rendered through the full_application_window component model.

On Windows the application opens a real GUI window using native controls. The workspace tree, inspector, and editor-state preview are driven by the components shared library, allowing UI modules to be hot-swapped without recompiling the host executable.
