Overview

The LSP Applications directory contains a suite of Language Server Protocol frontend executables, one per supported language. Each binary wraps a language-specific LSP library and exposes a standard LSP JSON-RPC interface over stdio so that any compliant editor can provide language intelligence for that target language.

All frontends share the same thin entry-point pattern: initialise the corresponding *_lsp_lib static library, hand off I/O to the LSP loop, and exit cleanly on shutdown. Deployment targets: Linux, macOS, Windows.

C++17 LSP / JSON-RPC Multi-language stdio transport Cross-platform
