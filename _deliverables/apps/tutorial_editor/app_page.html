Overview

The Tutorial Editor is a lightweight Python/Tkinter desktop application for authoring .tut files — the source format used by the CoolBox tutorials pipeline. It provides a visual insert-action toolbar, real-time preview generation, and direct save into the top-level tutorials/ directory.

Tutorials authored here are consumed by _scripts/build_tutorials.py to produce static HTML pages for the documentation site. Optional drag-and-drop support is available via tkinterdnd2 if installed.

Python 3 Tkinter GUI Tutorial authoring Static site generation

How to Run

Launch from the repository root:

# Windows
python apps\tutorial_editor\tutorial_editor.py

# macOS / Linux
python apps/tutorial_editor/tutorial_editor.py

No build step required — the script runs directly from source. Ensure the .venv is active so that project imports resolve correctly.

Supported Insert Actions

  • @title1 / @title2Section and sub-section headings
  • @tagsMetadata tags for the tutorial index
  • @libsLibrary references rendered as dependency cards
  • @imageInline image block (file path or URL)
  • @videoEmbedded video block
  • @linkHyperlink shortcut
  • @repoRepository badge linking to source
  • paragraphFree-form prose block
