# CoolBox Swift Bindings

Swift package wrapper surface for CoolBox integration.

## Build

```bash
cd _deliverables/libraries/bindings/swift_bindings
swift build -c release
```

## Surface

- `CoolBoxSwiftBindings.version`
- `CoolBoxSwiftBindings.ping()`

This package is scaffolded so the Extensions tab can discover and build Swift bindings consistently with other language bindings.
