This tutorial demonstrates how to generate and visualize a sine wave using Python with NumPy and Matplotlib.

Introduction

Generating waveforms is a fundamental task in signal processing and scientific computing. Here, we'll create a simple sine wave and plot it.

Prerequisites

You need to have `numpy` and `matplotlib` installed. You can install them with:

pip install numpy matplotlib

Step 1: Import Libraries

import numpy as np
import matplotlib.pyplot as plt

Step 2: Generate the Sine Wave

# Parameters
frequency = 5  # Hz
sampling_rate = 500  # Hz
duration = 2  # seconds
t = np.linspace(0, duration, int(sampling_rate * duration), endpoint=False)
y = np.sin(2 * np.pi * frequency * t)

Step 3: Plot the Wave

plt.figure(figsize=(10, 4))
plt.plot(t, y, label=f'{frequency} Hz Sine Wave')
plt.xlabel('Time [s]')
plt.ylabel('Amplitude')
plt.title('Sine Wave Generation with NumPy')
plt.legend()
plt.grid(True)
plt.tight_layout()
plt.show()

Conclusion

You have generated and visualized a sine wave using Python. You can modify the frequency, sampling rate, or duration to explore different waveforms.
