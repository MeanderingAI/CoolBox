Detailed Description

Models a single battery cell.

Tracks voltage, capacity, state of charge (SoC), internal resistance, and temperature. Provides methods to simulate discharge/charge cycles and compute open-circuit voltage from SoC using a linearised model.

Open-circuit voltage model (linear approximation): V_oc(SoC) = V_min + SoC * (V_max - V_min)

Terminal voltage under load: V_terminal = V_oc(SoC) - I * R_internal
